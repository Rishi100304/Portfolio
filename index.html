Inclusive E-Commerce Platform

An inclusive e-commerce web application built with Next.js and TypeScript, designed to make online shopping more accessible and convenient for users from diverse backgrounds. The platform integrates external APIs to display a wide range of products, including cosmetics and food items, while providing a fast, responsive, and user-friendly shopping experience. A key focus of the project is accessibility. Each product offers three different ways for users to explore its details:

  • 📖 Read – View detailed product information in a traditional text format.
  • 🎙️ AI Voice Assistance – Listen to product descriptions through AI-generated voice narration, making the platform more accessible for users with dyslexia, visual impairments, or anyone who prefers listening over reading.
  • 📱 QR Code Viewing – Generate a QR code that allows users to instantly open the product page on their mobile device, providing flexibility for users who may not have access to a laptop or desktop.
The application also includes modern e-commerce functionality such as product search, secure authentication, and customizable themes. Users can sign in using their Google account, allowing for a quick and secure login experience without creating a separate account. The interface also supports Light Mode, Dark Mode, and System Theme, enabling users to personalize their browsing experience.

Key Features

  • 🛍️ Browse products fetched from external APIs
  • 🍎 Explore categories including food and cosmetics
  • ⭐ View product ratings
  • 🔍 Search products instantly
  • 📖 Read detailed product information
  • 🎙️ AI-powered voice narration for improved accessibility
  • 📱 QR code generation for viewing products on mobile devices
  • 🔐 Secure authentication with Google Sign-In
  • Light, Dark, and System theme support
  • ⚡ Responsive and optimized user interface built with Next.js and TypeScript

Purpose

This project was developed to make online shopping more inclusive and accessible. By combining assistive technologies such as AI voice narration, QR code accessibility, and a clean user interface, the platform helps reduce barriers for individuals with dyslexia, visual impairments, limited literacy, or those who prefer using mobile devices. The goal is to create a shopping experience that is accessible, intuitive, and welcoming for a wide range of users.

Weather Application using APIs

A responsive weather application built with HTML, CSS, and JavaScript that provides users with real-time weather information by integrating a weather API. The application allows users to search for any city and instantly view current weather conditions, including temperature, humidity, wind speed, and overall weather status. It also focuses on error handling by notifying users when an invalid city is entered or when weather data cannot be retrieved. Designed with a clean and intuitive interface, the application delivers a seamless experience across desktop and mobile devices.

Key Features

  • 🌍 Search weather information for any city
  • 🌤️ Displays real-time weather conditions using a Weather API
  • 🌡️ Shows temperature, humidity, wind speed, and weather status
  • 🔄 Fetches live data asynchronously using JavaScript
  • ❌ Handles invalid city names and API errors gracefully
  • 📱 Fully responsive design for desktop and mobile devices
  • ⚡ Dynamic UI updates without page refresh

Purpose

This project was developed to strengthen my understanding of API integration, asynchronous JavaScript, and dynamic DOM manipulation. It provided hands-on experience working with real-time data, handling asynchronous requests using fetch(), implementing error handling, and creating an interactive application that delivers live information to users.
